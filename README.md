# Growth Check 360 - Team Assessment Platform

A comprehensive SaaS platform for organizational assessment, evaluating team effectiveness across six critical dimensions: Agile Maturity, Teamwork, Innovation, Leadership, Engagement, and Digital Adoption.

## Features

- **Six Assessment Dimensions**: Comprehensive evaluation across critical team areas
- **Anonymous Assessments**: Token-based secure quiz sessions with configurable expiry
- **Company Organization**: Multi-team management with scoped data access
- **Dual Authentication**: Google OAuth and email/password login
- **Real-time Analytics**: Color-coded performance bands with exportable reports
- **Freemium Model**: Tiered subscription plans with usage limits
- **Email Integration**: SendGrid for password resets and notifications

## Tech Stack

- **Frontend**: React 18 + TypeScript + Vite
- **Backend**: Node.js + Express + TypeScript
- **Database**: PostgreSQL with Drizzle ORM
- **Authentication**: Google OAuth + custom email/password
- **Payments**: Stripe integration
- **Email**: SendGrid
- **UI**: Tailwind CSS + shadcn/ui + Radix UI
